## How to Create a Token

Create an authentication token in four steps:

1. **Open your profile**  
   Click your name at the top right of the Cyber Console and choose **Profile**, or go directly to the [profile page](https://app.aegister.com/settings/profile/).

2. **Create a new token**  
   In the **API tokens** card, click **+ New token**.
   <img className="block dark:hidden" src="/images/console/api-tokens-light.webp" alt="API tokens" />
   <img className="hidden dark:block" src="/images/console/api-tokens-dark.webp" alt="API tokens" />

3. **Name the token**  
   Enter a name and click **Generate**.
   <img className="block dark:hidden" src="/images/console/new-token-light.webp" alt="Generate new token" />
   <img className="hidden dark:block" src="/images/console/new-token-dark.webp" alt="Generate new token" />

4. **Copy the token**  
   Copy the token now. It is not shown again after you close the dialog.
   <img className="block dark:hidden" src="/images/console/token-created-light.webp" alt="Token generated" />
   <img className="hidden dark:block" src="/images/console/token-created-dark.webp" alt="Token generated" />


Store the token securely. Every API request requires it, sent in the `X-Aegister-Token` header (see [Authentication](/api-reference/authentication)).
