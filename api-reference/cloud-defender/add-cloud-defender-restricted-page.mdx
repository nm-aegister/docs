description: "Restrict one or more paths of a domain to the addresses you list, with optional exceptions. Use a `preset` (wordpress, joomla, drupal, phpmyadmin) for a common admin area, or give your own `prefixes`. A new restricted page starts in test: Cloud Defender logs what it would refuse and lets it through, until you switch it to enforced. Owners and security officers with a live licence."
