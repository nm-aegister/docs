title: "Associate workflow to organization"
sidebarTitle: "Associate workflow"
description: "Enable a compliance framework (workflow) for an organization, for example NIS 2 or ISO 27001:2023: afterwards its controls, tasks and documents are available for evaluation. It is the same as switching the framework on in the organization's Compliance tab, or declaring it in `data.compliance_frameworks` with “Update organization”. A framework associated before comes back with its evaluations. Get the workflow id from the available-workflows list."
openapi: post /api/v1/v-ciso/organizations/{organizationid}/workflows/{workflowid}
