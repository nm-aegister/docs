## Come creare un token

Crea un token di autenticazione in quattro passaggi:

1. **Apri il tuo profilo**  
   Clicca sul tuo avatar in alto a destra nella Cyber Console e scegli **Profilo**, oppure vai direttamente alla [pagina del profilo](https://app.aegister.com/settings/profile/).

2. **Crea un nuovo token**  
   Nella scheda **Token API**, clicca su **Nuovo token**.
   <img className="block dark:hidden" src="/images/console/api-tokens-it-light.webp" alt="Token API" />
   <img className="hidden dark:block" src="/images/console/api-tokens-it-dark.webp" alt="Token API" />

3. **Assegna un nome al token**  
   Inserisci un nome e clicca su **Genera**.
   <img className="block dark:hidden" src="/images/console/new-token-it-light.webp" alt="Genera nuovo token" />
   <img className="hidden dark:block" src="/images/console/new-token-it-dark.webp" alt="Genera nuovo token" />

4. **Copia il token**  
   Il token compare sopra l'elenco dei token. Clicca subito su **Copia**: viene mostrato una sola volta, e **Fatto** lo nasconde definitivamente.
   <img className="block dark:hidden" src="/images/console/token-created-it-light.webp" alt="Token generato" />
   <img className="hidden dark:block" src="/images/console/token-created-it-dark.webp" alt="Token generato" />


Conserva il token in modo sicuro. Ogni richiesta API lo richiede, nell'header `X-Aegister-Token` (vedi [Autenticazione](/api-reference/it/authentication)).
