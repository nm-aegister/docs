---
title: "Associa un workflow a un'organizzazione"
sidebarTitle: "Associa workflow"
description: "Abilita un framework di conformità (workflow) per un'organizzazione, per esempio NIS 2 o ISO 27001:2023: dopo l'associazione i suoi controlli, attività e documenti sono disponibili per la valutazione. Equivale ad attivare il framework nella scheda Conformità dell'organizzazione, o a dichiararlo in `data.compliance_frameworks` con «Aggiorna organizzazione». Un framework associato in passato torna con le sue valutazioni. Ottieni l'id del workflow dall'elenco dei workflow disponibili."
openapi: post /api/v1/v-ciso/organizations/{organizationid}/workflows/{workflowid}
---
