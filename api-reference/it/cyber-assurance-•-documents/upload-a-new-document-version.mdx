---
title: "Carica una nuova versione del documento"
sidebarTitle: "Carica versione"
description: "Carica un file di evidenza come JSON in base64: PDF, Word, Excel, immagine o video, al massimo 10 MB. Il path restituito è quello da allegare come evidence nella risposta a un controllo o a un'attività. Effettua la deduplicazione tramite checksum SHA256: se lo stesso contenuto esiste già per questo artefatto, restituisce la versione esistente (200) invece di crearne una nuova (201). Rimuove le versioni più vecchie oltre le 10 per artefatto."
openapi: post /api/v1/v-ciso/organizations/{organizationid}/workflows/{workflowid}/documents/{artifactid}/versions
