description: "Aggiungi un'applicazione web a Cloud Defender: il suo dominio (`fqdn`; un nome di dominio internazionale va nella forma `xn--`, come lo invia la procedura guidata), l'indirizzo del tuo server di origine (`endpoint`) e l'organizzazione a cui appartiene. È ciò che fa la procedura guidata di configurazione dopo la sua verifica; esegui prima «Verifica un'applicazione web» per controllare che dominio e origine rispondano come previsto. Aegister prepara poi il dominio e «Passaggi di attivazione» ne segue l'attivazione fino a quando è attivo. Puoi aggiungere applicazioni web solo per le organizzazioni che puoi gestire."
