sidebarTitle: "Elenco rilevamenti"
description: "Recupera le richieste che Cloud Defender ha riconosciuto come corrispondenti alle firme di attacco per un dominio protetto.

Un rilevamento registra com'era la richiesta, non necessariamente cosa le è successo: mentre un dominio appena protetto viene tarato le sue regole restano in anteprima, quindi un rilevamento può indicare cosa sarebbe stato bloccato. Il campo outcome indica cosa è realmente accaduto."
