Un rilevamento registra com'era la richiesta, non necessariamente cosa le è successo: le regole di firma sono attualmente in modalità anteprima, quindi un rilevamento indica cosa sarebbe stato bloccato. Il campo outcome indica cosa è realmente accaduto."
