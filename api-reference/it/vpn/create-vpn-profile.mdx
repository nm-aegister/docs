description: "Crea un profilo VPN per una persona della tua organizzazione: invia l'`organization` e l'`email` della persona (nella GUI: Virtual Private Network → Gestisci VPN → Nuovo profilo VPN). Gli altri campi vengono ignorati: il profilo riceve da Aegister il certificato e il nome account dell'organizzazione. Richiede il ruolo Owner e una licenza VPN attiva con un posto libero. La persona diventa membro dell'organizzazione e riceve un'email con le istruzioni per collegarsi."
