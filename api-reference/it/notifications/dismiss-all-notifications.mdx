title: "Rimuovi tutte le notifiche di un servizio"
sidebarTitle: "Rimuovi tutte di un servizio"
description: "Rimuovi dal tuo elenco tutte le notifiche di un servizio (`service`, obbligatorio), per esempio tutte quelle di Cloud Defender. Gli altri membri dell'organizzazione continuano a vederle. Il servizio è obbligatorio perché la campanella non venga svuotata per errore. Entro 10 minuti puoi riportarle con «Annulla rimozione»."
openapi: put /api/v1/notifications/dismiss-all
