description: "Import into a task: table rows (JSON/XLSX) or question answers (JSON). dry_run validates and returns normalized data, the table's current rows and errors without saving; otherwise it validates, submits to scoring, and records a new evaluation. By default the rows replace the table; keep_rows updates matching rows and keeps the others. Error messages follow lan (en or it). Requires the edit role."
